# Echte Stockfotos statt KI-Bilder

Die 8 KI-generierten Bilder werden durch echte, lizenzfreie Fotos von Unsplash/Pexels ersetzt (kommerziell nutzbar, keine Namensnennung nötig). Auswahl nach warmen Braun-/Beige-Tönen (Holz, Leder, Bücher, Papier, warmes Licht), passend zu "Espresso & Creme".

## Zuordnung

| Bild | Motiv des Stockfotos |
|---|---|
| Startseite (Bibliothek) | Juristische Bibliothek, Holzregale, warmes Licht |
| Kontakt | Schreibtisch mit Füller, Papier, Leder |
| Krypto/Finanzen | Münzen/Dokumente auf Holztisch, warm |
| Leitartikel (Justitia) | Justitia-Statue bzw. Richterhammer auf Holz |
| Partner BKA | Aktenordner/Ermittlungsakten, warmes Büro |
| Partner Coinbase | Besprechung am Holztisch |
| Partner Binance | Laptop/Zusammenarbeit, warme Töne |
| Partner IOSCO | Konferenzsaal, gedämpftes Licht |

## Umsetzung

- Fotos herunterladen, auf passende Größe zuschneiden, als CDN-Assets hochladen.
- Bei Bedarf leichter warmer Farbfilter (Sepia/Wärme), damit alles einheitlich wirkt — keine Blautöne.
- Alle Verweise im Code auf die neuen Fotos umstellen, alte KI-Bilder löschen.
- Optisch prüfen (Startseite, Kontakt, Rechtsgebiete, Partner).

Team-Fotos bleiben unverändert (waren keine KI-Bilder dieses Redesigns).
